# Just3000

Just3000 is an iOS vocabulary learning app focused on helping users master the 3,000 most common English words through consistent daily practice.

The project is also designed as a learning journey for exploring **Local & Cloud Data** implementation in iOS development.

## Project Goals

- Help users learn and review common English vocabulary.
- Provide a simple, focused, and motivating learning experience.
- Support daily practice and long-term progress tracking.
- Explore local data persistence and cloud synchronization in iOS.
- Build a scalable SwiftUI project structure.

## Tech Stack

- Swift
- SwiftUI
- SwiftData
- CloudKit
- Xcode

## Main Features

- Home dashboard for daily learning overview.
- Library for browsing and searching vocabulary.
- Practice flow for reviewing words.
- Progress tracking for learning consistency.
- Settings for app preferences.
